# big-org-example-operations — BeamScale

An internal-operations workload emphasizing actor isolation, auditable middleware, rate-limit/cache behavior, and OTEL evidence. Forms and sync drive operator workflows; chat/conversation integrations attach collaboration context without widening the hosted P3 capability set.

All external ORES integrations cross the trusted P2 boundary through approved injected operations. Shared TypeSpec and JSON Schema contracts keep operation identity comparable with Scintilla and ORES Stack.

```sh
bmscl check .
bmscl build . --out-dir dist
bmscl deploy dist --project big-org-example-operations --environment dev --dry-run
bmscl deploy dist --project big-org-example-operations --environment dev
```
