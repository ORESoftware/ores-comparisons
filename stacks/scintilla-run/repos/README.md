# Optional source checkouts

Reserve this directory for pinned git submodules when a benchmark needs the Scintilla implementation tree. Useful pins include `scintilla-cli`, `scintilla-lambda-pub-core`, `scintilla-interfaces`, `scintilla-lib-core`, and `scintilla-run-infra`.

The committed projects themselves use Scintilla's public endpoint/process contracts and do not require mutable branch checkouts.
